Build a highly interactive, visually experimental personal portfolio website for a Product Designer named Jasmine.

The website should feel like a digital creative experience rather than a traditional corporate portfolio. The visual direction should combine minimal editorial design, bold typography, playful graphics, smooth scroll animations, and immersive interactions.

Overall aesthetic
Dark background, primarily near-black: #080808
High-contrast white typography
Occasional vibrant accent colors inspired by stickers, digital art, gradients, and playful design elements
The website should feel expressive, youthful, creative, and slightly unexpected
Avoid generic SaaS portfolio layouts, card grids, excessive glassmorphism, or standard template aesthetics
Use lots of negative space
Make typography the primary visual element
The experience should feel polished, cinematic, and interactive
Navigation

Create a floating navigation bar centered at the top of the page.

The navigation should be a rounded pill with:

Home
Approach
Work
About

The currently active section should have a light/white pill background while inactive links remain dark.

On the left side, place a custom handwritten or expressive wordmark for Jasmine.

On the right side, include:

hello@jasminendodo.com

The navigation should remain visible while scrolling and smoothly update the active section.

HERO SECTION

Create a dramatic full-screen hero section.

The main statement should be large, centered, and animated:

Building digital experiences that make people stop, think, and feel.

Or alternatively:

I design products, brands, and experiences for people, not just screens.

Use oversized editorial typography with subtle scroll-based animation.

The text should reveal progressively as the user scrolls or enters the page.

The background should remain almost completely black to create strong focus on the typography.

Add subtle cursor interactions or floating elements that react to mouse movement.

APPROACH SECTION

Create a storytelling section explaining how I approach design.

Instead of a traditional list of skills, present the process as a sequence of bold, animated words.

For example:

LISTEN

Understanding people, problems, and the context behind them.

EXPLORE

Researching possibilities, asking questions, and identifying opportunities.

FOCUS

Turning complexity into clear product decisions.

DESIGN

Creating thoughtful, accessible, and intuitive experiences.

REFINE

Testing, learning, iterating, and improving.

Each stage should take over the screen as the user scrolls.

Use large condensed typography that dominates the viewport.

Include subtle animated shapes or visual elements entering from the edges of the screen.

INTERACTIONS AND ANIMATIONS

Use smooth, premium animations throughout the website.

Include:

Lenis smooth scrolling
GSAP ScrollTrigger animations
Framer Motion for UI transitions
Scroll-driven typography changes
Text reveal animations
Parallax effects
Cursor-following elements
Magnetic buttons
Subtle image scaling and distortion
Smooth section transitions

Animations should feel intentional and cinematic, not distracting.

Prioritize performance and accessibility.

Respect prefers-reduced-motion.

TYPOGRAPHY

Use a combination of:

A bold, condensed display typeface for large headings.
A clean modern sans-serif for body text and UI.

Typography should be oversized and expressive.

Use uppercase for major section titles such as:

WORK
FOCUS
DESIGN
ABOUT

Allow typography to occasionally overlap images and other visual elements.

RESPONSIVE DESIGN
